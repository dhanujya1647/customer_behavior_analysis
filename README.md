# Customer Behavior Analysis Dashboard

### 📊 Project Overview
End-to-end data analysis project analyzing 3,900+ customer purchase records to identify key trends in demographics, sales patterns, and product performance.

### 🎯 Key Insights Delivered
- **Total Customers Analyzed**: 3.9K
- **Average Purchase Amount**: $59.76  
- **Customer Rating**: 3.75/5.0
- **Top Segments**: Identified by age, gender & category

### 🛠️ Tech Stack
- **Python**: Data cleaning & EDA using Pandas, NumPy, Matplotlib
- **SQL**: Querying and aggregating datasets  
- **Power BI**: Interactive dashboard with DAX measures
- **Jupyter Notebook**: Full analysis documentation

### 📈 Dashboard Features
1. KPI Cards for total sales, customers, avg purchase
2. Demographic breakdown by age & gender charts
3. Category-wise sales performance visuals
4. Interactive filters for deeper analysis

### 💡 Business Impact
This dashboard enables businesses to:
- Identify high-value customer segments
- Optimize inventory based on top-selling categories
- Target marketing campaigns by demographic insights
